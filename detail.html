1. 어떻게 동작하나요

서버가 방송 채팅에 직접 접속해 시청자 활동을 실시간으로 기록합니다. 확장 프로그램은 하루에 한 번 SOOP 통계에서 시청자 랭킹을 가져와 서버로 올립니다.

PC를 꺼도 채팅 달란트는 계속 쌓입니다. 채팅 수집은 서버가 하기 때문입니다. 다만 랭킹 가산점은 확장이 담당하므로 브라우저를 며칠 켜지 않으면 그동안의 랭킹이 밀립니다. 다시 켜면 최근 7일치를 자동으로 메웁니다.
달란트는 스트리머별로 따로 쌓입니다. A 스트리머에게 모은 달란트로 B 스트리머의 보상을 교환할 수 없습니다.
SOOP 비밀번호는 요구하지 않습니다. SOOP의 공식 로그인 화면에서 권한을 허용할 뿐, 비밀번호를 SoopTalent에 전달하지 않습니다. 공식 토큰으로 방송국 소유자를 확인하므로 별도 아이디 연동 신청도 필요하지 않습니다.

2. 시작하기

1

SOOP으로 로그인합니다

이 사이트에서 SOOP 로그인 버튼을 누르고 방송 여부·방송국 정보·채팅 권한을 허용합니다. 서버가 공식 정보로 방송국을 바로 확인하므로 별도 아이디 입력이나 관리자 승인이 필요 없습니다.

2

확장 프로그램을 설치합니다

Chrome Web Store에서 스트리머 확장을 설치한 뒤, 크롬 오른쪽 위 퍼즐 메뉴에서 SoopTalent 아이콘을 고정해 두세요.

3

확장에서도 SOOP으로 로그인합니다

확장 아이콘을 누르고 SOOP 로그인을 완료합니다. 웹과 확장의 세션은 보안을 위해 따로 보관하지만, 공식 API가 확인한 같은 방송국 계정으로 자동 연결됩니다.

4

연결 상태를 확인합니다

대시보드에 SOOP 공식 인증됨과 SOOP 공식 Chat SDK가 보이면 즉시 채팅 수집이 시작됩니다. 문제가 있을 때는 Discord @cagea1로 알려 주세요.

계정 불일치 경고가 뜬다면 — 브라우저가 승인된 계정과 다른 SOOP 계정으로 로그인돼 있다는 뜻입니다. 이 상태로는 랭킹이 올라가지 않습니다.

3. 달란트가 쌓이는 방법

활동방식설명
방송 시청자동 채팅 참여자 목록에 머무는 동안 일정 시간마다. 기본 10분마다 5달란트입니다.
채팅자동 채팅 한 건마다. 도배로 쌓지 못하도록 분당 인정 건수와 하루 상한이 걸려 있습니다.
별별랭킹 시청시간 / 채팅 순위 자동 전날 순위 상위 100명에게 순위에 따라 가산점을 줍니다.
후원자동 별풍선과 애드벌룬을 개수에 비례해 환산합니다. 환산율을 따로 정할 수 있습니다.
첫 후원 팬클럽 가입자동 첫 후원의 신규 팬클럽 번호로 확인하며 기존 팬에게 중복 지급하지 않습니다.
구독자동 공식 이벤트로 구독·연속 구독·구독 선물을 구분하고 개월 수에 따라 적립합니다.
게시글 · 댓글수동 방송국 게시판에서 버튼을 눌러 직접 지급합니다.
직접 지급수동 대시보드의 직접 지급 탭에서 아이디·금액·사유를 넣어 줍니다. 회수하려면 음수를 넣습니다.
SOOP 공식 API·Chat SDK 연동
로그인할 때 방송 여부, 방송국 정보, 채팅 메시지 권한을 함께 허용합니다. 서버는 공식 SDK로 본인 방송의 채팅과 후원·첫 후원 팬클럽·구독 이벤트를 받고, 액세스 토큰이 만료되기 전에 자동 갱신합니다. 기존 사용자는 새 권한 동의를 위해 SOOP으로 한 번 다시 로그인해야 합니다.

채팅 연동 켜고 끄기

대시보드 탭 맨 위 연결 상태 카드에서 채팅 연동을 끌 수 있습니다. 끄면 서버가 방송 채팅에서 빠져나오고, 방송 시청·채팅·별풍선/애드벌룬 후원·첫 후원 팬클럽·구독 달란트가 멈춥니다.

  • 별별랭킹 동기화·게시판 직접 지급·달란트 시장은 채팅 연동과 별개라 그대로 동작합니다.
  • 이미 쌓인 달란트는 사라지지 않습니다. 달란트 시장도 그대로 열립니다.
  • 설정은 서버에 저장되어 서버를 다시 켜도 꺼진 채로 유지됩니다.
  • 다시 켜면 방송 중일 때 몇 초 안에 붙습니다. 끈 동안의 활동은 메워지지 않습니다.

내역 확인

달란트 내역 탭에서 누가 언제 왜 받았는지 한 줄씩 볼 수 있습니다. 시청자 아이디나 사유로 걸러서 볼 수 있습니다.

[2026-08-11 01:38:56] 홍길동(user123) +500 달란트 / 이벤트 당첨 보상
달란트 기준을 바꾸면 과거 달란트도 바뀌나요?

아닙니다. 변경한 기준은 저장 이후에 발생하는 활동부터 적용됩니다.

같은 사람이 여러 기기로 접속하면 중복으로 쌓이나요?

아닙니다. 동시 접속은 하나의 계정으로 합쳐서 계산합니다.

방송을 안 보고 켜만 둬도 쌓이나요?

쌓입니다. 자리를 비운 시청도 참여로 인정하도록 설계했습니다. 부담스러우면 달란트 기준 탭에서 지급 주기를 늘리거나 회당 달란트를 낮추면 됩니다.

4. 게시판에서 직접 주기

방송국 게시글과 댓글 옆에 버튼이 나타납니다. 게시글 버튼은 추천 버튼 바로 옆에, 댓글 버튼은 답글 옆에 있습니다.

쪽지 보내기

달란트를 준 뒤 쪽지 버튼을 누르면 그 시청자에게 스트리머 본인 계정으로 쪽지를 보낼 수 있습니다. 문구가 미리 채워지지만 보내기 전에 확인하고 고칠 수 있습니다.

쪽지는 자동으로 나가지 않습니다. 버튼을 누를 때만 한 통씩 보냅니다. 지급할 때마다 자동 발송하면 받는 분의 쪽지함이 차고, 대량 발송은 스팸으로 판정돼 스트리머 계정이 제재될 수 있습니다.
같은 글에 두 번 줄 수 없습니다. 실수로 여러 번 눌러도 한 번만 지급됩니다. 지급 내역에는 어떤 글·댓글이었는지 링크가 함께 기록됩니다.
댓글 버튼은 다른 방송국에서도 쓸 수 있나요?

네. 댓글 달란트는 어느 방송국의 글이든 줄 수 있습니다. 게시글 버튼은 본인 방송국에서만 나타납니다.

5. 달란트 시장 (보상 교환)

보상을 걸어 두면 시청자가 모은 달란트로 신청합니다. 달란트 시장 탭에서 관리합니다.

1

보상 페이지를 만들고 보상을 등록합니다

보상마다 이름 · 가격 · 총 수량 · 인당 제한 · 미리보기 사진을 넣습니다. 사진은 사각형 칸을 눌러 올립니다 (PNG·JPEG·GIF·WebP, 2MB 이하).

항목비우면설명
총 수량무제한 이 페이지에서 풀리는 전체 개수입니다. 선착순으로 소진됩니다.
인당 제한무제한 한 사람이 가져갈 수 있는 최대 개수입니다. 총 수량이 남아 있어도 한 명이 독식하지 못하게 막습니다.

둘 다 걸면 더 빡빡한 쪽이 먼저 걸립니다. 예를 들어 총 수량 10개 · 인당 2개면, 최대 5명이 2개씩 가져갑니다.

2

공유 링크를 만들고 시청자에게 보냅니다

페이지 열기를 누르면 추측하기 어려운 시장 링크가 만들어집니다. 게시글 주소를 등록할 필요 없이 이 링크를 시청자에게 직접 공유하면 됩니다.

시장은 목록이나 검색에서 공개하지 않습니다. 링크를 아는 사람만 접근할 수 있는 비공개 공유 링크 방식입니다.

3

시청자가 사이트에서 바로 구매합니다

시청자는 링크에서 SOOP으로 로그인하고 보상과 수량을 고릅니다. 구매 시점에 서버가 보유 달란트·총 수량·인당 제한을 확인한 뒤 즉시 달란트를 차감하고 주문을 기록합니다.

4

시장 종료와 구매 내역

구매 내역은 결제될 때마다 바로 쌓입니다. 시장 닫기를 누르면 링크는 즉시 종료되며, 이미 열어 둔 화면에서도 더 이상 구매할 수 없습니다.

한 번 닫으면 다시 열 수 없습니다. 닫힌 링크는 410 Gone으로 응답해 “이 달란트 시장은 종료되었습니다”만 보여 줍니다. 달란트·총 수량·인당 제한 중 하나라도 모자라면 차감은 일어나지 않습니다.
차감의 근거는 서버의 결제 트랜잭션입니다. 화면에서 보낸 수량은 그대로 믿지 않고, 서버가 로그인한 SOOP 아이디 기준으로 잔액·수량·인당 제한을 다시 검사합니다.
시청자는 무엇을 설치해야 하나요?

아무것도 설치할 필요가 없습니다. 공유 링크를 열고 SOOP으로 로그인하면 됩니다.

시장 링크를 다른 사람에게 전달해도 되나요?

링크를 받은 사람은 접근할 수 있습니다. 특정 사람만 받게 하려면 링크를 그 사람에게만 전달해 주세요.

6. 문제가 생겼을 때

승인 대기 상태가 계속됩니다

운영자가 직접 확인하고 승인하는 방식입니다. Discord @cagea1로 DM을 보내 주시면 빠르게 확인해 드립니다. 승인되면 자동으로 인식하므로 다시 신청할 필요는 없습니다.

“SOOP 로그인 계정이 승인된 스트리머와 다릅니다”

브라우저가 다른 SOOP 계정으로 로그인돼 있습니다. 잘못된 데이터가 올라가지 않도록 업로드를 일부러 중단한 상태입니다. 스트리머 계정으로 로그인한 뒤 확장에서 지금 동기화를 누르세요.

랭킹 달란트가 며칠째 들어오지 않습니다

SOOP 통계는 전날 데이터를 새벽 6시경에 확정합니다. 오늘 방송분은 내일 반영됩니다. 그보다 오래 밀렸다면 대부분 로그인 문제입니다.

채팅 달란트는 쌓이는데 랭킹만 안 들어옵니다

채팅은 서버가, 랭킹은 확장이 담당합니다. 확장 쪽만 문제가 있다는 뜻이므로 SOOP 로그인 상태와 확장 프로그램 상태를 확인하세요.

달란트가 전혀 쌓이지 않습니다

대시보드 탭 맨 위 연결 상태 카드를 먼저 보세요. 어디가 끊겼는지 한 줄로 나옵니다. 확장 팝업에서도 같은 내용을 볼 수 있습니다.

  • 채팅 연동이 꺼짐 — 직접 끈 상태입니다. 옆의 켜기를 누르세요.
  • 방송 대기 — 방송이 꺼져 있습니다. 고장이 아닙니다.
  • 재접속 중 — 연결을 다시 준비하는 중입니다. 잠시 뒤에도 계속되면 방송을 껐다 켜거나 SOOP으로 다시 로그인해 주세요.
  • 서버 응답 없음 — 서버나 데이터베이스가 꺼져 있습니다.
게시판에 버튼이 보이지 않습니다

로그인과 승인이 끝나야 나타납니다. SOOP이 페이지 구조를 바꾸면 일시적으로 안 보일 수 있는데, 그 경우에도 엉뚱한 사람에게 달란트가 가지는 않습니다.

쪽지가 보내지지 않습니다

상대가 쪽지 수신을 거부했거나, 짧은 시간에 너무 많이 보내 제한에 걸렸을 수 있습니다. 잠시 후 다시 시도해 주세요.

SoopTalent은 SOOP의 공식 서비스가 아닙니다.
